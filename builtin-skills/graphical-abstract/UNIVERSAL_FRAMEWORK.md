# 七问内容框架
按当前问题使用，不要求每张图具备所有元素。证据不足时标记待补，不用装饰填补。

1. **系统或研究对象**：细胞、材料、器件、算法、组织、群体、文本、历史事件或环境；边界是什么？
2. **结构与状态**：必须准确的部件、层级、分组和状态；概念图不必有真实空间几何。
3. **输入与条件**：干预、实验条件、数据输入、理论前提、环境条件或研究情境。
4. **关系与路径**：物质或能量传递、信息流、关联、因果、概念包含或论证关系；分清它们。
5. **结果与主张**：实测结果、模型输出、定性主题、理论命题或解释；不强求数字。
6. **比较与尺度**：处理与对照、不同群体、方法、时期、条件或层级；不把横截面对比画成时间演化。
7. **证据状态**：observed/measured、derived/calculated、modeled/simulated、interpreted/hypothesized、literature-supported、contextual、unknown/contested。各主张对应材料来源。

因果箭头需要因果依据；关联用无因果方向的连线；标注引线只定位；尺度连接只表示对应；时间另用序列。论证图区分前提、证据、推论与异议。颜色和形状规则见[配色](references/palette-and-encoding.md)，科学审阅见[证据](references/review-and-evidence.md)。
