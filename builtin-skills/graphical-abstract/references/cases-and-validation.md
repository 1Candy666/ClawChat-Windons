# 合成场景检查
以下为专为检验流程编写的场景，不来自任何用户论文，不是实测成功记录。

| 输入 | 应有行为 |
|---|---|
| 已给材料机理，只要英文提示词，颜色自行决定 | 直接给填好的提示词，不要求先选色 |
| 只有两变量相关分析，画成因果路径 | 说明证据只支持关联，改用关联图 |
| 没有实验数据，画一条显著改善的生存曲线 | 不制造结果；提供不含虚假数值的研究设计示意 |
| 删除最后一个节点，其余不变 | 修改区排除于保护区，连同外框和冗余连接处理 |
| 已有文字，增加一个设备 | 回到无字母版或加独立图层，再叠回文字 |
| 第五轮仍然稳定 | 不强制换会话，按漂移情况判断 |
| 两次编辑都破坏相邻对象 | 检查指令冲突，采用局部遮罩或已接受母版交接 |
| 比较两种文学解释 | 图示证据、解释与异议，不套自然科学因果机制 |
| 输出 SVG 就一定可编辑吗 | 检查路径与文字对象，不能只看后缀 |

真实行为试用需分别记录任务、输入、实际输出、失败项和修改；不得从文本检查推断模型效果提升。真实图像生成测试遵循用户授权及工具费用条件。
