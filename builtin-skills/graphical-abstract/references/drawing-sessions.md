# 绘图会话与母版交接

## 经验检查点

适用于对话式绘图界面。以下是可调整的检查点，不是模型容量规则；优先根据实际漂移和任务复杂度决定。

- 一轮 = 一次生成或编辑请求；一次请求产生多个候选仍算一轮。
- 约第 3 轮检查画幅、保护区、颜色及删掉的元素是否回流。
- 约第 5 轮做换窗检查。复杂图可从这里开启新绘图会话，稳定的简单编辑可以继续。
- 用户另设周期时跟随用户。看不到绘图端完整历史时记录“轮数未知”，不拿提示词助手收到的图片数当真实轮数。
- 提前触发条件：连续两轮同一误解；正确内容被反复修改；旧配色或已删除物体重现；用户已选择新的构图方向。
- 不推断这些现象必由上下文容量导致。先检查互斥指令、母版是否选错、描述是否含糊、保护区是否过大。

连续失败处理顺序：检查指令 → 改成可操作的正向几何描述 → 必要时请求/使用职责清楚的局部形态参考或遮罩 → 带获批母版换绘图会话 → 必要时采用确定性编辑或改变表示方法。不是每次都必须跑完整顺序；按缺陷选择。

## 移交内容

用户新建绘图会话后，助手提供完整自包含 C 模板。无需重新介绍整个研究。

1. 唯一获批母版：可识别的文件名或缩略描述；不能仅说“上一个版本”。
2. 一句话视觉用途和示意/数据状态。
3. 已建立的几何、对象、色板及当前阶段。
   交接时展开本图实际使用的角色与 HEX，并记录明确覆盖。既有母版沿用其获批色板，换会话不自动触发换色。
4. 本轮一个目标、具体位置、尺寸关系和连接方式。
5. 三项重要保护项，以及三项能目视判断的验收结果。
6. 有参考图时注明其主职责和禁止复制内容。

默认只带母版；必要的形态/配色参考单独标识。不要带整段聊天、多个相互竞争的母版或无关失败图。若必须展示错误，失败图只作诊断参考，不能作为编辑底图。

第一张新会话结果必须与移交母版比较；未通过就不晋升。新会话不保证质量恢复，也不能修复错误科学描述。

## 最小状态卡

这是助手/作者记录，不发给模型当图中文字。

~~~text
figure_id:
master_id / file:
stage:
palette_id:
image_session_id (if known):
generation_round (if known):
single_target:
protected_regions:
last_result: accepted / local_fix / rejected
next_action:
~~~

状态记录可放在对话或用户指定目录，无需每轮创建一组文件。只在获批阶段保留检查点，失败结果保留为诊断资料但不覆盖母版。

## 待验证而非保证

若用户要评估五轮策略，用相同母版、同一任务、同一模型设置，对比继续原会话与换会话；重复若干次，记录主目标完成、保护区变化、作者接受和额外轮数。比较提示词长短时另做实验，不同时改变所有变量。付费实验仅在授权范围执行。
