# 跨学科图文摘要原型
按信息关系选择，不按专业固定选一种外观。

| 原型 | 适合的信息 | 关键检查 |
|---|---|---|
| 对象—过程—结果 | 实验机制、材料转化、生物过程 | 过程有证据，箭头方向准确 |
| 输入—方法—输出 | 算法、测量系统、研究设计 | 数据流与因果关系分开 |
| 并列比较 | 干预对照、方法比较、理论比较 | 比较维度一致，不凭面积暗示数值 |
| 结构剖面或空间场景 | 器件、组织、装置、环境 | 部件位置与尺度有依据 |
| 时间序列 | 阶段演变、事件顺序、纵向设计 | 时间顺序不自动证明因果 |
| 网络或概念关系 | 社会网络、概念框架、理论关系 | 边类型和节点意义清楚 |
| 多尺度嵌套 | 分子到系统、样品到器件、个人到组织 | 放大关系与不同样本不能混同 |
| 论证地图 | 人文研究、理论文章、证据综合 | 前提、解释、异议与结论可区分 |
| 示意加数据面板 | 研究机制和关键结果结合 | 数据面板从真实数据绘制 |

每个面板承担一个任务；需要混合时明确主次。三维平台、实验装置或地图都不是默认必备元素。
