# 启动提示词
以下发给负责提示词与审图的助手；实际图像会话使用已填好的模板。

```text
请使用图文摘要技能，根据我提供的研究材料提炼一条核心信息，按本学科选择合适构图。不要补造数据、机制或引用。用我的交流语言讨论，给我可独立复制的英文绘图提示词；只有我明确要求生成时才调用图像工具。
先确定对象、关系、结果与证据，参考图分别声明布局、形态、颜色等职责。没有参考图时可依据材料设计，不固定使用三维平台。颜色按当前领域和已有图决定，简要列出实际颜色与用途；我已让你自行决定时直接继续。
复杂图分阶段，一轮一个主目标。图形先做无字版，正式文字保留为独立层。给局部编辑提示时明确唯一母版、目标和保护区。
我发回结果后，请检查结构、视觉、科学含义和保护区，决定接受、局改或回滚。最新结果不自动成为母版；重复失败先检查指令冲突，必要时带母版与状态卡换会话。最终交付无字图、文字清单和所需导出，不声称未经验证的像素一致或矢量可编辑性。
```
