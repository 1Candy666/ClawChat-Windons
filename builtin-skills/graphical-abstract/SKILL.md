# 图文摘要 · Graphical Abstract

## 任务与边界
根据当前论文和读者确定图要传达的一个核心信息。适用于自然科学、医学、工程、计算机、社会科学和人文学科的研究示意；按学科使用机制、比较、概念关系、论证结构或研究流程，不把所有研究画成因果机制。
跟随用户交流语言；绘图提示词默认英文，可按目标工具调整。默认只提供提示词；用户明确要求生成或编辑图片时使用可用图像工具。真实曲线、统计、地图、化学结构与需要精确语法的图形交给适当的确定性工具，不让图像模型伪造测量结果。
不补造数据、阈值、实验设备、机制和引用。只对会改变科学含义或编辑对象的缺失信息澄清；没有参考图也可依据充分的材料构图。

## 工作过程
1. 用一句话写明视觉主旨，辨明对象、状态、驱动或输入、关系、结果、比较与证据。每个面板有明确任务。
2. 有现成图时指定唯一编辑母版；其他参考分别声明布局、形态、方向、色彩或内容职责。风格参考不能提供本研究的数据和科学结论。
3. 简要列出对象与颜色的映射及 HEX。已有配色沿用；用户让助手决定时直接给合理方案；只有要求选色或存在关键语义歧义时等待选择。没有跨学科通用的材料色板。
4. 复杂图按构图与几何、主要对象、过程连接、样式、独立文字层推进；简单图可以合并阶段。一轮一个主目标或少数紧密相关目标。
5. 初次或换会话提供完整自包含提示词；稳定会话局部编辑提供已填好的短提示词。明确目标、位置、保护区、颜色和可观察验收标准。修改区不得同时被锁定；删除包含外框和相关连接。
6. 图形阶段保留 `no text, no letters, no numbers, no labels, no legend text, no watermark, no pseudo-writing`；正式标签之后单独排版。
7. 对照真实图像检查结构、视觉、科学含义和保护区，给出 Accept as master / Local refinement only / Rollback。最新结果不自动替代获批母版。

## 交付
通常交付一句判断、最多三个关键问题及一段可独立复制的提示词。只问含义就解释；只要提示词就输出填妥的提示词。状态只需记录母版、阶段、配色、本轮目标及接受情况，不必每轮建文件。
主体完成后保留原分辨率无字母版、标注清单、独立文字层和导出文件。透明度、像素一致及矢量可编辑性须实际验证；生成式图片经矢量重建后仍保留生成来源。投稿要求按具体期刊核对。
