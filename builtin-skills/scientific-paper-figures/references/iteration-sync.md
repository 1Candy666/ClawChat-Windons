# Versions and synchronization

Project rules and current authorization govern propagation. Trials are candidates; acceptance applies to the reviewed version, not scientific/publication approval. Acceptance alone does not authorize propagation to other destinations where the project requires explicit consent. “Finalize and synchronize” authorizes that batch; do not ask again or extend it to later trials.

## Local iteration

Keep one current entry and the last accepted snapshot; backups stay outside delivery paths. Edit target source, requested exports and local handoff; identify captions/collections awaiting synchronization. A changed linked image does not update its caption.

Reuse a manifest or small collection mapping: figure ID → source → current exports → caption → order. After manual moves, renames, exclusions or SI renumbering, verify actual paths. Never recreate deliberately removed folders or omitted figures.

## Authorized propagation

1. Verify version identity and unchanged numbers, or revised statistics/scope.
2. Update affected captions/workbook metadata from the same definitions; unchanged tables need no rebuild.
3. Update guides, numbering, cross-references and collections. Preserve source artwork when assigning SI numbers; honour exclusions. Keep unaccepted trials out unless requested.
4. Reopen exports, inspect changed pages/panels and check links. Verify collection order and current source renders; existence, timestamps or process exit alone are insufficient. Finish unlocked outputs and identify blocked ones without claiming full synchronization.
5. Update any explicitly requested project index last, once per batch, preserving unrelated records and author judgments.

Keep handoff brief: accepted/candidate paths, differences, next step, pending decisions and propagation. Use the current project’s requested status convention; do not create or read personal logs for routine figure work.
