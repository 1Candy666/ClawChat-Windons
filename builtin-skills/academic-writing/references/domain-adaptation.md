# 学科与研究类型适配
只收集会影响本次任务的信息，可从已有材料推断；不要把配置表变成强制问卷。

| 配置 | 用途 |
|---|---|
| 学科、研究对象与读者 | 术语、证据形态及解释深度 |
| 文章类型与研究设计 | 选择章节、报告单位及因果边界 |
| 当前材料与证据来源 | 防止补造数据、方法和引用 |
| 目标期刊及语言 | 格式、字数与语体 |
| 可选风格样本 | 仅提取本次用户允许的表达偏好 |

医学与生命科学重点区分研究人群、终点与干预证据；理工科重点区分材料条件、测量与模型；计算研究重点区分数据划分、比较条件与外部验证；社会科学区分抽样、关联与因果识别；定性与人文研究核对语境、原始文本与解释链；数学与理论研究核对假设、量词、定义和证明边界。跨领域能力指可配置流程，不代表预装全部学科事实。
