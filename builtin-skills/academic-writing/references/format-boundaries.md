# 格式与全文核对
期刊控制摘要结构、字数、标题层级、图表样式、引文、声明及附加摘要；不要从已排版论文推断投稿模板。未知要求记录为未知，不强制默认字数、小节数或结论条数。

全文检查：
1. 确认文章类型与已提供的期刊规范；需要最新规范时核对原始作者指南。
2. 比较问题、方法、结果、论证与结论，记录缺失证据。
3. 检查摘要与正文的对象、数字、范围和证据强度一致性。
4. 核对图表及补充材料首次引用、编号、图注、单位和误差定义。
5. 保持术语和缩写稳定；不合并专业上不同的概念。
6. 核对引用是否支持对应论点，缺少来源不编造。
7. 只按真实情况填写作者贡献、资助、利益冲突、伦理、同意及数据代码可用性；不得自动写“无”。
8. 需要时运行随附脚本辅助计数和引用顺序检查，人工判断其提示；DOCX 文本解析不代表版面审阅。

运行示例（限制来自当前用户提供的期刊规范时才填写）：
`python "<skill-directory>/scripts/audit_manuscript.py" manuscript.md --abstract-max 300`
未提供限制时脚本只报告计数和可识别引用，不臆定期刊要求。非英文标题或复杂文档需人工复核。
